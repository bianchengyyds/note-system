接口文档（统一响应体版）

- **基础路径**：`/api`
- **认证方式**：JWT，通过 `Authorization: Bearer <token>` 传递
- **统一响应格式**：

```JSON
{
  "code": 1,
  "msg": "success",
  "data": {}
}
```

编码：1成功，0为失败

- **笔记类型枚举**：`doc`（富文本文档）、`table`（表格）、`board`（画板/看板）、`mind`（思维导图）

### 2.13 知识库全量导出

```Plaintext
GET /kb/{kbId}/export
```

- **响应**：`.lakebook` 格式文件流，Content-Type: `application/octet-stream`，无 JSON 响应体
- **权限校验规则**：校验当前登录用户对该`kbId`知识库至少拥有「查看权限」，无权限直接返回 403 错误。

### 2.14 导入文档到目标知识库

```Plaintext
POST /kb/{kbId}/import
```

- **请求格式**：`multipart/form-data`（专门用于上传文件的格式）
- **请求字段**：

| 字段名 | 类型            | 是否必填 | 说明                                                         |
| ------ | --------------- | -------- | ------------------------------------------------------------ |
| files  | MultipartFile[] | 是       | 上传的文件数组，支持批量多文件上传，**支持格式及对应规则严格对标语雀，分类如下**：▌一、系统自有格式（无损还原，导出导入闭环）1. `.lakebook`：知识库迁移文件，完整还原目录结构、笔记层级与元数据2. `.lake`：系统单笔记专属格式，无损还原为单篇富文本文档/表格/画板/思维导图3. `.lakeboard`：看板专属格式，还原为可编辑在线看板4. `.laketable`：表格专属格式，还原为可编辑在线表格▌二、三方通用格式（兼容外部文件导入）1. 文档类：`.doc/.docx`、`.md`、`.txt`、`.ppt/.pptx`，解析为可编辑富文本文档2. 表格类：`.xlsx/.xls`、`.csv`，解析为可编辑表格笔记3. 预览类：`.pdf`、`.jpg/.png`，生成带原生预览的笔记，支持可选文本提取 |

- **响应**：通用 JSON 响应体

```JSON
{
  "code": 1,
  "msg": "导入成功",
  "data": {
    "successCount": 5,
    "failCount": 0,
    "failList": []
  }
}
```

- **权限校验规则**：校验当前登录用户对该`kbId`知识库必须拥有「编辑 / 写入权限」，无权限直接返回 403 错误，拒绝接收文件。

### 3.16 导出笔记

```
GET /note/{noteId}/export/{format}
```

- **格式对应说明**：

| format 枚举值 | 生成文件后缀   | 说明                                                         |
| ------------- | -------------- | ------------------------------------------------------------ |
| word          | `.docx`        | 生成 Word 文档，仅富文本文档支持                             |
| markdown      | `.md` / `.zip` | 单篇富文本文档生成.md，带图片的文档生成.zip 压缩包（含 md 文件 + 图片素材），对标语雀 Markdown 导出 |
| pdf           | `.pdf`         | 生成 PDF 文件，保留排版样式，富文本文档/表格/画板支持        |
| lake          | `.lake`        | 系统自有单笔记专属格式，无损还原笔记样式、元数据，仅支持本系统导入 |
| jpg           | `.jpg`         | 生成笔记长图，富文本文档/画板支持                            |
| xlsx          | `.xlsx`        | 生成 Excel 文件，仅表格笔记支持                              |

- **响应**：对应格式的文件流，Content-Type 精准匹配：
  - Word: `application/vnd.openxmlformats-officedocument.wordprocessingml.document`
  - Markdown: `text/markdown`（单文件）/ `application/zip`（压缩包）
  - PDF: `application/pdf`
  - lake: `application/octet-stream`
  - JPG: `image/jpeg`
  - XLSX: `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`
- **权限校验规则**：校验当前登录用户对该笔记所属知识库至少拥有「查看权限」，无权限直接返回 403 错误。

- **接口路径**：`POST /admin/statistics/refresh`
- **权限要求**：`ADMIN`
- **请求参数**：

| 参数名   | 类型   | 必填 | 说明                                         |
| :------- | :----- | :--- | :------------------------------------------- |
| statDate | string | 否   | 指定统计日期（格式：YYYY-MM-DD），默认为昨天 |

## 补充说明

1. **回收站恢复与彻底删除**已通过 `/note/{noteId}/restore` 和 `/note/{noteId}/permanent` 实现。
2. **笔记类型**：`type` 字段支持 `doc`（富文本文档）、`table`（表格）、`board`（画板/看板）、`mind`（思维导图），预留扩展。
3. **审核状态**：建议在 `note` 表增加 `audit_status` 字段（0待审核 1通过 2驳回），与 `is_public` 配合：只有 `is_public=1` 且 `audit_status=1` 的笔记才会在公开列表展示。接口 `PUT /admin/notes/{noteId}/audit` 用于更新该字段。
4. **统计表**：`daily_stat` 建议通过定时任务每天凌晨聚合前一天数据，后台接口直接读取。
5. **分页参数**：所有原带 `page` 和 `size` 的接口均已移除查询参数，后端必须提供默认值（如 `page=1, size=20`）。若前端需要自定义分页，可通过请求头或额外的参数传递（具体实现可自行约定）。
6. **文件流接口**：所有返回文件流的接口（如下载、导出、备份）无 JSON 响应体，仅返回对应 Content-Type 的二进制流。
7. **失败响应示例**：若接口调用失败，响应格式统一为：

```JSON
{
  "code": 0,
  "msg": "失败原因描述",
  "data": null
}
```
