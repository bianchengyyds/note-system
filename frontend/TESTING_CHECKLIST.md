## 📊 性能测试

### 11. 虚拟滚动测试

**测试场景**: 包含大量段落的文档

**测试步骤**:
1. 创建一个包含 100+ 段落的文档
2. 快速滚动文档
3. 观察滚动流畅度
4. 打开浏览器开发者工具
5. 检查 DOM 节点数量

**预期结果**:
- ✅ 滚动流畅（60 FPS）
- ✅ DOM 节点数量合理（不是 100+）
- ✅ 无明显卡顿

**性能指标**:
```javascript
// 在控制台运行
performance.mark('scroll-test')
// 快速滚动文档
performance.measure('scroll-duration', 'scroll-test')
console.log(performance.getEntriesByName('scroll-duration'))
```

---

### 12. 懒加载测试

**测试场景**: 包含多个嵌入组件的文档

**测试步骤**:
1. 创建一个包含 5 个嵌入组件的文档
2. 打开 Network 面板
3. 刷新页面
4. 观察初始加载时的 API 请求数量
5. 逐个悬停在组件上
6. 观察每次悬停时的 API 请求

**预期结果**:
- ✅ 初始加载时没有组件数据请求（或很少）
- ✅ 悬停时才发起对应的 API 请求
- ✅ 已加载的组件不会重复请求

**检查点**:
```javascript
// 在控制台监控 API 请求
const originalFetch = window.fetch
window.fetch = function(...args) {
  console.log('API Request:', args[0])
  return originalFetch.apply(this, args)
}
```
